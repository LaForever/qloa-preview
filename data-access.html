Resource policy

Data access policy

QLOA is a query-first database for record lookup, biological exploration and interactive visualization.

Public record access

Individual Cq_V4 gene records, longest-isoform sequences, tissue summaries, abundance profiles and filtered results in the biological resource explorers are available without registration. Small gene-list analyses can be submitted through the Tools page.

Data required to render an interactive graphic are transferred to the browser and must not be treated as secret. Sensitive or embargoed data are not included in public visualization payloads.

Direct downloads

The application directly serves low-risk release metadata, including the tissue dictionary and assay sample metadata. Bulk study files are not distributed through the interactive application.

Repository-managed data

Complete abundance matrices, full annotation exports, complete derived tables and network edge lists will be linked through verified transcriptome, proteome and release archives after repository publication.

Programmatic access

Documented read-only endpoints support lightweight gene, tissue and search lookups. Other JSON routes are implementation interfaces for the website and are not a stable bulk-download contract. Automated harvesting, endpoint enumeration and high-volume use are unsupported.

Reuse

Reuse is governed by the licences identified for the relevant QLOA release. Until licences are assigned in the release metadata, public visibility must not be interpreted as permission for unrestricted reuse.
