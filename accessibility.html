Resource policy

Accessibility statement

Current accessibility features, known limitations and a route for reporting barriers.

Interface support

QLOA is designed for keyboard and pointer use across desktop and mobile viewports. The interface provides a skip link, semantic headings, labelled form controls, visible focus states, text alternatives for content images and tabular alternatives for major interactive visualizations where practical.

Known limitations

Some dense heatmaps, network diagrams and scatter plots require zooming or scrolling and may be less efficient with assistive technology. Gene lists, tables and detail panels provide text-based access to the records represented by these graphics.

Report a barrier

Accessibility problems can be reported to huangheng2000@sjtu.edu.cn. Include the page URL, browser or assistive technology and a description of the barrier.

This statement describes the current design intent and known limitations; it is not a claim of formal conformance certification.
