Privacy statement

How QLOA handles browser preferences, submitted queries and routine service information.

Application data

QLOA does not require an account and does not include advertising or third-party analytics. The browser application stores one functional preference, the most recently selected Data Resources module, in local storage on the user's device.

Gene identifiers, gene lists and sequences submitted to QLOA tools are processed to answer the current request. The application does not intentionally write submitted query content to the atlas database. Do not submit confidential, personal or otherwise sensitive sequence data.

Server logs

The public host or reverse proxy may process routine connection information such as IP address, request time, requested URL, response status and user agent for security and service operation. The responsible production institution, retention period and deletion policy will be identified before the atlas is designated publication-ready.

Contact

Questions about scientific content or application data handling may be sent to Heng Huang at huangheng2000@sjtu.edu.cn. Security reports should follow the security policy.

This page describes application behavior. Infrastructure-level retention terms remain subject to the policy of the final production host.
